A. Presentación del Problema

¿Qué es ordenar datos?

Es el proceso de organizar elementos de una colección en una secuencia específica (ascendente o descendente) basado en un criterio de comparación lógica.

Tipos de datos soportados:

  • Numéricos: Enteros (`int`) y de punto flotante (`float`).
  • Cadenas de texto (`str`): Ordenación mediante equivalencia de caracteres alfabéticos (ASCII).

Objetivo del Método Shell Sort

Optimizar el ordenamiento por inserción directa tradicional al permitir la comparación e intercambio de elementos que se encuentran en posiciones distantes, reduciendo drásticamente los desplazamientos necesarios.

Situación Real de Aplicación

Sistemas embebidos y dispositivos IoT con memoria RAM extremadamente limitada que necesitan procesar y ordenar ráfagas de lecturas rápidas sin incurrir en desbordamientos de pila causados por recursión masiva.

C. Explicación Matemática y Resolutiva

El comportamiento resolutivo del algoritmo se fundamenta en las siguientes certezas lógicas:

  • Garantía de Término: El ciclo principal evalúa de forma estricta la condición `salto > 0`. Como la brecha se recalcula mediante división entera (`salto //= 2`), disminuye de forma monótona convergente hasta alcanzar el valor `0`, deteniendo el programa.
  • Certeza del Ordenamiento: En su iteración final, opera con un `salto == 1` (inserción directa). Al haber aproximado previamente los elementos pesados a sus zonas en pasadas anteriores, la lista requiere un esfuerzo mínimo para finalizar ordenada al 100%.

Análisis de Complejidad Temporal (Nivel Introductorio)

Escenario Técnico Complejidad Formal Descripción Operacional
Mejor Caso Ω(n log n) La lista ya se encuentra ordenada. Realiza las comparaciones de brecha obligatorias pero efectúa cero intercambios en memoria.
Caso Promedio O(n1.5) Depende de la secuencia de brechas escogida. La reducción sucesiva por la mitad ofrece un rendimiento balanceado y eficiente.
Peor Caso O(n2) Ocurre cuando los elementos mayores se encuentran intercalados de forma simétrica, forzando desplazamientos máximos.

D. Implementación Técnico en Python

def shell_sort(lista):
    largo = len(lista)
    
    if largo <= 1:
        return lista
        
    salto = largo // 2
    
    while salto > 0:
        for i in range(salto, largo):
            valor_temporal = lista[i]
            posicion = i
            
            while posicion >= salto and lista[posicion - salto] > valor_temporal:
                lista[posicion] = lista[posicion - salto]
                posicion -= salto
                
            lista[posicion] = valor_temporal
            
        salto //= 2
        
    if len(lista) > 0 and isinstance(lista[0], (int, float)):
        lista_limpia = [int(x) if hasattr(x, 'is_integer') and x.is_integer() else x for x in lista]
        return lista_limpia
        
    return lista

entrada_usuario = input("Ingrese una lista (pueden ser números enteros, decimales o palabras) separados por espacios: ")

Puntos Críticos de la Implementación

  • Uso Estricto de Funciones: Recibe la colección directamente como parámetro y efectúa un `return` limpio.
  • Prohibición de Métodos Nativos: No se utiliza `sort()` ni `sorted()`, garantizando el desarrollo manual puro.
  • Variables Comprensibles: Se reemplazan nomenclaturas ambiguas por términos explícitos en español (`salto`, `valor_temporal`, `posicion`).
  • Manejo Óptimo de Memoria: Opera de forma In-place modificando los índices internos existentes.

F. Verificación de Casos de Prueba

1. Lista Inversa y Desordenada

Entrada descendente extrema: [9, 7, 5, 3, 1] → [1, 3, 5, 7, 9].

2. Lista con Elementos Repetidos

Claves duplicadas: [4, 2, 4, 1, 2] → [1, 2, 2, 4, 4].

3. Lista con Valores Negativos

Bajo el cero relativo: [-5, 10, 0, -2] → [-5, -2, 0, 10].

4. Lista Vacía o Unitaria

Límite de datos: [] → [] (Retorno limpio).

G. Análisis Funcional y Limitaciones

Manejo de Mutabilidad en Memoria

El algoritmo opera bajo la propiedad In-place. Modifica los índices dentro del espacio físico de la lista original pasada por referencia, con una complejidad espacial constante de O(1), evitando duplicar el consumo de hardware.

Estabilidad del Algoritmo

Shell Sort se clasifica como un algoritmo INESTABLE. Debido a los saltos distantes intermedios, si existen dos registros con idéntica clave, no se garantiza que mantengan su prioridad relativa inicial.

Detección de Errores y Limitaciones de Python

El script implementa la ordenación de tipos de datos puros homólogos (cadenas de texto o números).

Falla Crítica por Tipos Mezclados: Si la entrada contiene colecciones mixtas heterogéneas, ej: `[3, "Informatica", -1]`, el intérprete lanzará un error del tipo TypeError. Esto ocurre porque las restricciones internas prohíben la evaluación relacional lógica del operador `>` entre instancias numéricas y cadenas.

H. Ventajas, Limitaciones y Comparación Formal

Ventajas Principales

  • Eficiencia de Recursos: No requiere asignación de estructuras auxiliares adicionales.
  • Rendimiento Evolucionado: Desplaza ágilmente elementos pesados, superando la lentitud cuadrática del método Burbuja básico.

Limitaciones Técnicas

  • Inestabilidad Estructural: Inviable para sistemas que exijan mantener ordenaciones multi-criterio en registros duplicados.
  • Dependencia Matemática: Su optimización final depende plenamente del patrón secuencial de brechas configurado.

Recomendaciones de Implementación

¿Cuándo se recomienda?
En proyectos de automatización, microcontroladores o sistemas IoT con restricciones estrictas de memoria RAM.

¿Cuándo NO es conveniente?
Se descarta en Big Data o repositorios masivos indexados (donde dominan *Merge Sort* o *Heap Sort*), o donde la consistencia de elementos duplicados sea una regla estricta.

I. Conclusiones y Lecciones del Proyecto

  • Aprendizaje del Grupo: Comprendimos cómo una variación lógica (comparar elementos espaciados mediante saltos) transforma radicalmente la eficiencia computacional de un programa.

  • Aspecto Más Relevante Evaluado: El núcleo técnico prioritario fue dimensionar el impacto real de la selección del algoritmo idóneo frente a las capacidades e infraestructuras de hardware disponibles.
